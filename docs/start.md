我想做一个 AI mettign/会议任务

用 node 起一个 web 服务，前端用 react。

页面分为 3 个部分：
左边是项目列表， 可以创建一个项目， 项目中默认名字为当天时间， 可以选择默认的模型，选项关联的文件夹
一个项目创建好后，创建一个默认的听写。


中间部分是会议听写页面。
有个按钮，点击后开始进行听写， 目前支持中文/英语/德语（暂时支持3个，后面可以选择）。
听写分为 3 级：
1. 即时听写， 时时写出听到的词语
2. 把整句语音进行听写
3. AI 把当前句和前面的句进行更新改写。 如果原文是其他语音，附加中文翻译（可以选择）
结果也要实时写入一个本地文件
听写一定要速度快，能第一时间显示出别人说了什么， 页面性能要好。
另外能需要区分人



右边是和 Agent 聊天对话。
在中句对话页面可以选中一些字，或者点住一句话，以这句话为 reference 让用户可以提问， 用户可以键入问题， 然后右边是和 AI 对话的信息。
可以选择 模型和思考强度。交互一定要方便



和 AI agent 的交互可以加工适配层，这样以后可以切换不同的 ai hernes， 现在先只用 pi hernes。 包括。

第一阶段只做 左边和中间部分。速度一定要快，性能一定要好。
注意我只有 codex/ claude code 的订阅， 没有 API 额度。 所以一定要支持订阅的方式。
代码设计架构要分号层级：这样方便以后换不同的听写模型， AI 翻译，AI 模型等等
也要设计凉后的文件结构


我最后目标是：
我在开会后，可以启动这个软件
它会时时的听写所有的内容， 我不用耳朵听，通过看也知道会议再讲什么
让后我可以继续追问，让 AI 回答会议中遇到的问题（这个步骤是第二阶段）
